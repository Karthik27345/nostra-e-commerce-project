#  Nostra — Responsive E-Commerce Website

Nostra is a fully responsive fashion e-commerce website built using HTML, Tailwind CSS, and JavaScript.  
The project demonstrates modern UI design, responsive layouts, and interactive product filtering functionality.

🔗 **Live Demo:**  
https://karthik27345.github.io/nostra-e-commerce-project/

📦 **GitHub Repository:**  
https://github.com/Karthik27345/nostra-e-commerce-project

---

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Product filtering by color, arrival, and occasion
- Interactive product sections (New Arrivals & Most Wanted)
- Mobile sidebar navigation menu
- Clean UI built with Tailwind CSS
- Product badges (sale)
- Wishlist icons
- GitHub Pages deployment
